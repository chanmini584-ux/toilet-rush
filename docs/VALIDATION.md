## 통합 검사 범위

메뉴 → 도움말 → 시작, 키보드 이동·점프, 시간·게이지·이동의 일시정지, 설문 중 시간 진행과 일시정지 복귀, 실제 3개 선택지 버튼, 95%→60% 회복과 화장실 1회 제한, 실패 컷신 종료, 실패 후 이동 중지, 실제 재시작 버튼의 초기화, 음소거 버튼, 터치 포인터 핸들러, 일반·질주 전체 경로, 승리 결과 UI, LocalStorage 저장, 메인 메뉴 복귀를 확인했습니다.

코어 추가 회귀 검사에는 코요테 타임·입력 버퍼, 충돌 무적, 구멍 복귀, 미끄러운 감속, 정확히 100%가 된 프레임의 후속 이벤트 중단, 설문 1회 실행, 100ms 프레임 안정성, 화장실 중 일시정지 후 중복 회복 방지, 터미널 상태 입력 무효화가 포함됩니다.

## 시각 및 기기 검토

기본 브라우저 패널, 1440×1000 데스크톱 크기, 390×844 휴대폰 크기의 뷰포트에서 메뉴·실패 화면·설문 화면을 검토했습니다. 모바일 설문·도움말·일시정지 창은 큰 글씨와 터치 버튼을 사용합니다. 모바일 설문 화면의 일시정지 버튼으로 정지·복귀한 뒤 실제 선택지 버튼 3개로 게임에 돌아오는 것까지 확인했습니다. 표정별 화면과 이벤트 fixture는 시각 확인용이며 전체 경로 통과 증거와 구분합니다.

## 확인 범위의 한계

- 모바일 확인은 데스크톱 Chromium의 뷰포트 및 포인터 이벤트 검증입니다. 실제 iOS/Android 기기 검증은 실행하지 않았습니다.
- Web Audio 노드 생성·전환·음소거와 오류 없는 실행을 확인했습니다. 실제 스피커로 청취한 음질·음량 평가는 하지 않았습니다.
- 일반적인 컴퓨터 전체에 대한 성능 벤치마크와 Firefox/Safari 검증은 실행하지 않았습니다.
- 첨부된 시각 참고 이미지는 제공되지 않아 문서의 카툰 스타일 요구를 바탕으로 오리지널 코드 아트를 제작했습니다.
- `file://` 직접 열기는 브라우저 자동화 도구의 URL 정책이 허용하지 않아 실행 검증하지 못했습니다. 서버 없이 실행하도록 상대 경로와 일반 스크립트만 사용했으며, 실제 브라우저 검증은 로컬 HTTP 주소에서 진행했습니다.
